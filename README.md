# 👑 موقع عطورات السلطان

موقع إلكتروني مخصص لعرض التشكيلة الفاخرة من العطور، مصمم بواجهة عصرية جذابة وتجربة مستخدم سلسة تعكس فخامة المنتجات.

## 🚀 المميزات
- **تصميم متجاوب:** يعمل بكفاءة عالية على جميع أحجام الشاشات (كمبيوتر، تابلت، موبايل).
- **تصميم فخم:** استخدام ألوان ملكية (الأزرق الداكن والذهبي) مع تأثيرات زجاجية (Glassmorphism).
- **عرض المنتجات:** شبكة عرض منظمة وأنيقة للمنتجات.
- **سهولة التواصل:** روابط مباشرة للواتساب ومنصات التواصل الاجتماعي.

## 🛠 التقنيات المستخدمة
- **HTML5:** لهيكلة المحتوى.
- **CSS3:** للتنسيق الجمالي والتأثيرات التفاعلية (Grid, Flexbox).
- **Netlify:** للاستضافة السحابية السريعة.
